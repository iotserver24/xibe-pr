## Reporting a Vulnerability

We take the security of xibe-pr very seriously. If you have discovered a security vulnerability, please **DO NOT** discuss it in a public issue.

### How to Report

Please report security vulnerabilities by emailing [INSERT SECURITY CONTACT EMAIL] or by opening a **Security Advisory** in this repository (if enabled).

In your report, please include:

1. **Vulnerability Type**: e.g., XSS, SQL Injection, RCE.
2. **Affected Component**: Which part of the bot/site is affected.
3. **Reproduction Steps**: Detailed steps to reproduce the vulnerability.
4. **Proof of Concept**: Code or screenshots demonstrating the issue.

### Response Timeline

* **Acknowledgment**: We will acknowledge your report within 48 hours.
* **Assessment**: We will assess the severity and impact within 1 week.
* **Fix**: We will aim to release a patch or mitigation within 2 weeks of assessment, depending on complexity.

### Expectations

* You can expect us to treat your report with confidentiality.
* We expect you to not disclose the vulnerability publicly until 30 days after a fix has been released, or unless we give explicit permission.

Thank you for helping keep xibe-pr safe!
